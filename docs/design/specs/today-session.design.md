## 1. Контракт (что клиент получает, форма, не имена функций)

Имена функций и таблиц выбирает владелец бэкенда. Здесь зафиксировано, **какие поля нужны экрану**, чтобы клиенту ничего не пришлось вычислять.

**`TodaySummary`** — блок «Сегодня» и окно «Повторим?»:

| Поле | Тип | Где показывается |
| --- | --- | --- |
| `state` | `"no_words" \| "ready" \| "in_progress" \| "done" \| "nothing_due"` | выбор состояния блока (§5) |
| `budget_minutes` | `5 \| 10 \| 15` | запомненный выбор, выбран по умолчанию в окне |
| `plans` | запись для `5`, `10`, `15`: `{ tasks, minutes, review_count, new_count, new_sources: {folder_id, folder_name, count}[], pairs: {a, b}[], debt: { deferred_tasks } \| null }` | строка окна и строки блока меняются вместе с выбранным бюджетом, **без** запроса на каждое переключение |
| `progress` | `{ done, total } \| null` | кольцо и «Продолжить · осталось N» в `in_progress` |
| `recall_now` | `{ recalled, total }` | «Сейчас вы вспомните ~212 из 347 слов» |
| `tomorrow_tasks` | `number` | «Завтра: ~30 заданий» |
| `show_daily_prompt` | `boolean` | показывать ли окно. Сервер решает, когда начались новые сутки, отвечал ли пользователь сегодня и есть ли что повторять (daily-and-folder-study §2.3: нечего повторять и нет новых — окна нет) |

**Действия:** `setBudget(minutes)` — запомнить выбор. `dismissDailyPrompt()` — «Позже», до завтра. `startToday(minutes)` — начать или продолжить, возвращает сессию.

**`StudySession`** (общая для «Сегодня» и папки, см. `folder-study.design.md`): `{ session_id, portion: { index, count }, tasks: Exercise[] }`. Формат `Exercise` описан в `exercise.design.md` §1.

**`PortionResult`** — пауза: `{ portion: { index, count }, recalled, answered, stage_ups: { headword, reading, to_stage }[] (не больше 3), is_last }`.

**`DaySummary`** — итог дня: `{ advanced: { headword, reading, from_stage, to_stage }[], advanced_total, pairs_resolved: { a, b }[], tomorrow_tasks, extra_new: { count, tomorrow_delta } \| null }`. `extra_new` равен `null`, если новых слов в очереди нет. Тогда кнопки «Ещё 7 новых слов» нет.

Стадии всегда приходят кодом из шести: `new`, `meeting`, `recognize`, `recall`, `use`, `stable`. Подпись к коду даёт i18n (§8).

## 2. Frame (TZ §11, универсальные правила)

| Состояние | Primary Action | Secondary Action | Context | Exit |
| --- | --- | --- | --- | --- |
| Словарь, блок `ready` | «Начать» в блоке (`Button primary`) | «Изменить время» (`Button ghost`) открывает то же окно выбора минут | число заданий и минут, строки «Повторить / Новые слова / Разобрать пару», прогноз | таб-бар |
| Словарь, блок `in_progress` | «Продолжить · осталось N» (`Button primary`) | нет | кольцо прогресса, прогноз | таб-бар |
| Словарь, блок `done` / `nothing_due` | нет в блоке. Primary экрана — «Новая папка» в «Моём словаре» | «Можно поучить папку →» (`Button ghost`) переносит фокус на заголовок «Мой словарь» | «Готово на сегодня» / «На сегодня всё», прогноз на завтра | таб-бар |
| Окно «Повторим?» | «Начать · {{n}} минут» (`Button primary`) | «Позже» (`Button ghost`) | число «пора освежить · новых» для выбранного бюджета | «Позже», Escape, тап по затемнению — всё равно «Позже» |
| Сессия, задание | см. `exercise.design.md` | — | прогресс порции | `IconButton close` — выход без потерь |
| Пауза | «Дальше» (`Button primary`) | «Хватит» (`Button ghost`) — возврат в словарь, блок станет `in_progress` | итог порции | «Хватит» |
| Итог дня | «Готово» (`Button primary`) — в словарь | «Ещё 7 новых слов» (`Button secondary`) + строка нагрузки | продвинулись, решённые пары, прогноз | «Готово» |

**Один primary на экране словаря.** Сейчас в `MyDictionary.tsx:79-84` у «Новой папки» вариант `primary`. Когда в блоке есть «Начать» или «Продолжить», «Новая папка» становится `secondary`. В остальных состояниях блока (`done`, `nothing_due`, блока нет) она остаётся `primary`. Вариант передаётся в `MyDictionary` пропом, а не вычисляется внутри по данным урока.

**Почему «Готово» — primary в итоге дня, а «Ещё 7» — secondary.** Бюджет, который выбрал сам человек, исчерпан. Продолжение — осознанный выбор сверх плана с ценой на завтра (daily-and-folder-study §2.4, §6), и визуально подталкивать к нему нельзя.

## 3. Layout

### 3.1 Навигация

- `(tabs)/_layout.tsx`: `TAB_ITEMS` в порядке **Словарь, Загрузка, Настройки**.
- `(tabs)/index.tsx`: `Redirect` на `/dictionary` вместо `/upload`.
- Сессия — отдельный маршрут вне `(tabs)`, как `app/folder/[id].tsx`: таб-бара на экране задания нет.
- Кнопка «назад» браузера во время сессии — тот же выход без потерь, что и крестик. Перезагрузка страницы в сессии — продолжение с того же задания по `startToday` (сервер знает, где остановились).

### 3.2 Экран «Словарь», поле поиска пустое

Сверху вниз, внешние отступы экрана прежние (`px-lg`):

1. Заголовок `dictionary.title` и поле поиска — без изменений.
2. **Блок «Сегодня»** — `Card`, отступ до поля поиска `spacing.md`, до «Мой словарь» `spacing.lg`.
3. «Мой словарь» (`MyDictionary`) — без изменений, кроме варианта кнопки (§2) и мини-полоски на карточке папки (`folder-map.design.md` §4).

Как только в поле появился запрос, блок скрывается целиком, как сейчас скрывается «Мой словарь». Состояние блока при этом не сбрасывается.

### 3.3 Блок «Сегодня», состояние `ready`

Внутренний отступ `Card` — `spacing.lg`, промежутки между группами — `spacing.md`.

```
[Сегодня]                                    heading, role=header
[ring]  34 задания · ~8 минут                body semibold; ring = ProgressRing
                                             sizing.todayRing, value 0
Повторить ........................ 26        body / body semibold, tabular
Новые слова ...................... 5         + caption muted «из «Покупки»»
Разобрать пару ................... 买 / 卖   HanziText inline
[           Начать           ]               Button primary, во всю ширину
      Изменить время · 10 минут              Button ghost, по центру
Сейчас вы вспомните ~212 из 347 слов         caption muted
Завтра: ~30 заданий                          caption muted
```

- Строки статистики — `View` с `flex-row justify-between`, между строками `spacing.xs`. Число выровнено вправо. Вся группа ограничена по ширине `sizing.readingColumn`: на 1280 подпись и число не должны разъезжаться через весь экран.
- Строка «Новые слова» показывается, только если `new_count > 0`. Если `new_sources.length > 1`, подпись — «из «Покупки» и ещё {{n}}».
- Строка «Разобрать пару» показывается, только если `pairs.length > 0`. Первая пара — `HanziText inline`. Если пар больше одной — «и ещё {{n}}».
- **Долг** (`debt !== null`): строки «Новые слова» нет. Вместо неё `caption` тоном `default` на `accentSoft`-подложке (`rounded-md`, `px-md py-sm`): «Сначала освежим {{n}} слов, новые — завтра». Красного и слова «долг» нет.
- Кольцо `ProgressRing` декоративно (`decorative`): его смысл уже сказан текстом рядом.

### 3.4 Блок, состояние `in_progress`

Как `ready`, но строка счёта — «Осталось {{left}} из {{total}}», кольцо показывает `progress.done / progress.total`, primary — «Продолжить · осталось {{left}}». Строк «Повторить / Новые / Пара» нет: сессия уже собрана. «Изменить время» нет: бюджет сессии уже выбран.

### 3.5 Блок, состояния `done` и `nothing_due`

```
[Сегодня]                                    heading
Готово на сегодня                            body semibold   (done)
На сегодня всё. Следующее повторение —       body            (nothing_due)
завтра.
Завтра: ~30 заданий                          caption muted
Сейчас вы вспомните ~212 из 347 слов         caption muted
Можно поучить папку →                        Button ghost, выровнен по левому краю текста
```

Нажатие на «Можно поучить папку →» прокручивает список к заголовку «Мой словарь» и ставит на него фокус (у заголовка `tabIndex -1` на web). Кнопки «Начать» нет. Раньше срока повторять почти бесполезно (daily-and-folder-study §2.4).

### 3.6 Блок, состояние `no_words`

Блок **не рендерится**. Пустое состояние «Моего словаря» уже зовёт создать папку или загрузить файл.

### 3.7 Окно «Повторим?»

`Sheet` (снизу на узком экране, по центру с `sizing.sheetMaxWidth` на широком). Внутри `gap-lg`:

```
Повторим слова?                              heading, role=header
26 пора освежить · 5 новых                   body muted — из plans[selected]
( 5 мин ) ( 10 мин ) ( 15 мин )              SegmentedChoice, во всю ширину
[      Начать · 10 минут      ]              Button primary
             Позже                           Button ghost
```

- Когда окно открылось, выбран `budget_minutes`. Переключение сразу меняет вторую строку и подпись кнопки, данные берутся из `plans`. Сеть не нужна.
- «Начать» вызывает `setBudget` и `startToday` одним действием и открывает сессию. На время запроса у кнопки `loading`.
- «Позже», Escape, тап по затемнению и «назад» в браузере вызывают `dismissDailyPrompt`. Блок «Сегодня» остаётся.
- Если `plans[selected].new_count === 0` и `debt !== null`, строка — «Сначала освежим {{n}} слов, новые — завтра».
- Показывается только на вкладке «Словарь», только при `show_daily_prompt === true`, не больше одного раза за монтирование вкладки. Deep link на папку или на загрузку окно не открывает.
- **То же окно** открывается по «Изменить время» из блока, но с заголовком «Сколько времени сегодня?», а вместо «Позже» стоит «Отмена». Отмена бюджет не меняет.

### 3.8 Сессия

Полный экран. Оболочку задания, прогресс порции, выход и форматы задаёт `exercise.design.md`. Здесь — только переходы:

```
startToday → задания порции 1 → пауза 1 → … → последнее задание последней порции → итог дня
                   └── крестик / «назад» / «Хватит» → словарь (блок in_progress)
```

### 3.9 Пауза между порциями

Тот же маршрут, экран вместо задания. Колонка `sizing.readingColumn` по центру, вертикально — по центру свободной высоты, `gap-lg`:

```
Порция 2 из 4 готова                         title, role=header
[check] 9 из 10 вспомнили                    body semibold; Icon check, success
便宜 теперь «Вспоминаю»                       body; HanziText inline + stage label
袋子 теперь «Узнаю»                          (0–3 строки из stage_ups)
[        Дальше        ]                     Button primary
         Хватит                              Button ghost
```

- Слово в строке повышения показано `HanziText inline`, рядом `StageDot` его новой стадии (§9). Цвет — не единственный носитель: название стадии написано словом.
- Если `is_last`, паузы нет: после последнего ответа сразу открывается итог дня.

### 3.10 Итог дня

Колонка `sizing.readingColumn`, скролл, `gap-lg`:

```
Готово на сегодня                            title, role=header
Продвинулись: 7 слов                         heading
  袋子   Узнаю → Вспоминаю                   строка: HanziText inline · StageDot → StageDot + подписи
  小票   Вспоминаю → Использую
  … и ещё 2                                  caption muted (если advanced_total > показанных 5)
Пара 买/卖 — различаете                      body; по строке на pairs_resolved
Завтра: ~28 заданий                          body muted
[         Готово         ]                   Button primary
[     Ещё 7 новых слов   ]                   Button secondary (если extra_new)
Завтра прибавится ~12 заданий                caption muted, под secondary, связан с ним через accessibilityHint
```

- Маскот: `Mascot decorative size="small" mood="celebrating" showStage={false}` над заголовком. Он оформление, а не механика (TZ §15). Если `advanced_total === 0`, маскот `neutral`, а строки «Продвинулись» нет.
- «Ещё 7 новых слов» запускает раунд знакомства из очереди приёма, тот же поток, что в `folder-study.design.md` §4, только без папки. Его итог — итог раунда из той же спеки.

## 5. States

### Блок «Сегодня» (внутри словаря — остальной словарь работает при любом состоянии блока)

- **Loading:** `Card` той же структуры. Внутри `caption muted` «Собираем занятие на сегодня» (`learn.today.loading`), `accessibilityLiveRegion="polite"`. Маскота и полноэкранного `LoadingState` нет: блок не должен вытеснять словарь. При фоновом перезапросе блок показывает прежние данные.
- **Empty:** `no_words` — блока нет (§3.6). `nothing_due` — §3.5.
- **Error:** `Card`, внутри `body` «Не получилось собрать занятие на сегодня. Проверьте интернет.» (`learn.today.error`) и `Button ghost` «Попробовать ещё раз» (`learn.today.retry`). `ErrorState` не используется: это часть экрана, а не весь экран.

### Окно «Повторим?»

- **Loading:** окно не открывается, пока нет `TodaySummary`.
- **Error при «Начать»:** под кнопками `FeedbackBanner` «Не получилось начать. Проверьте интернет и попробуйте ещё раз.» (`learn.prompt.startError`). Окно остаётся открытым.
- **Error при «Позже»:** окно всё равно закрывается. Сбой не показывается: в худшем случае окно откроется ещё раз при следующем открытии.

### Сессия

- **Loading (первое задание):** `LoadingState` «Собираем задания» (`learn.session.loading`).
- **Loading (между заданиями):** экрана загрузки нет. Следующие задания порции уже пришли вместе с `StudySession`. Если следующая порция ещё не пришла к моменту «Дальше», у кнопки «Дальше» `loading`.
- **Error при загрузке:** `ErrorState`, title «Не получилось собрать задания» (`learn.session.error.title`), detail «Проверьте интернет. Ответы, которые вы уже дали, сохранены.» (`learn.session.error.detail`), retry «Попробовать ещё раз», continue «К словарю» (`onContinueAnyway`).
- **Empty:** сервер вернул сессию без заданий (всё сделано на другом устройстве) — `EmptyState` «На сегодня всё. Следующее повторение — завтра.» (`learn.today.nothingDue`), действие «К словарю» (`learn.session.toDictionary`).
- **Error ответа:** описан в `exercise.design.md` §6.

### Пауза и итог дня

- **Loading:** `LoadingState` «Подводим итог» (`learn.session.summaryLoading`).
- **Error:** `ErrorState` «Не получилось показать итог» + detail «Ответы сохранены.» + retry + «К словарю».

## 6. Theming

- Все фоны, рамки и тексты задаются через `className` с парой `dark:`: `bg-surface dark:bg-surface-dark`, `text-text-muted dark:text-text-muted-dark` и так далее. **`useTheme().colors` для фона и рамки не используется.** В `dictionary.review.md` R2 OQ4 (#56) таб-бар, покрашенный через `useTheme`, остался белым в тёмной теме статической web-сборки. Исключение — `ProgressRing` и SVG-иконки, у них цвет идёт пропом. Они уже в проекте и проверены в ревью Главной.
- Тёмная тема: `Card` получает рамку `border-dark` (так уже в `Card.tsx`). Подложка долга — `accent-soft-dark`, текст на ней — `text-dark`. Точки стадий — тёмная ветка шкалы `stage*`. Галочка — `success-dark`.
- Затемнение окна — `scrim` / `scrim-dark` внутри `Sheet`.
- Переход между заданием и паузой — затухание. При `useReducedMotion` — без анимации.

## 10. Acceptance

1. `apps/mobile/app/(tabs)/_layout.tsx`: `TAB_ITEMS` идут в порядке `dictionary`, `upload`, `settings`.
2. `apps/mobile/app/(tabs)/index.tsx` перенаправляет на `/dictionary`.
3. Блок «Сегодня» рендерится в `dictionary.tsx` только при `query === ""`, над `MyDictionary`, и не рендерится при `state === "no_words"`.
4. Ни один компонент фичи не вычисляет число заданий, минут, прогноз, `recall_now`, стадию или повышения. Все значения берутся из полей контракта §1. Единственная арифметика на клиенте — доля `ProgressRing` (`done/total`) и `total − done` для «осталось».
5. Выбор минут в окне меняет строку и подпись кнопки из `plans[selected]` без сетевого запроса. В обработчике переключения нет вызова репозитория.
6. Окно открывается только на вкладке «Словарь» при `show_daily_prompt === true`, не больше одного раза за монтирование. «Позже», Escape и тап по затемнению вызывают `dismissDailyPrompt`.
7. По умолчанию в окне выбран `budget_minutes`. «Начать» передаёт выбранное значение и в `setBudget`, и в `startToday`.
8. На экране словаря в любой момент не больше одного `Button variant="primary"`. При `ready` и `in_progress` «Новая папка» — `secondary`, в остальных состояниях — `primary`. Вариант приходит в `MyDictionary` пропом.
9. Состояния блока `ready`, `in_progress`, `done`, `nothing_due`, loading и error реализованы по §3.3–3.5 и §5. У каждого есть фикстура mock-репозитория и флаг выбора, по образцу существующих `EXPO_PUBLIC_MOCK_*`.
10. Долг (`debt !== null`) показан строкой `learn.today.debt` на подложке `accentSoft` / `accent-soft-dark`. Токены `danger` и `warning` в блоке, окне, паузе и итоге не используются.
11. Строки статистики блока лежат в контейнере с `max-width` = `sizing.readingColumn`.
12. Сессия — маршрут вне `(tabs)`. Крестик, «назад» браузера и «Хватит» ведут в словарь без диалога подтверждения.
13. Пауза показывает `portion.index / portion.count`, `recalled / answered` и до 3 строк `stage_ups`. При `is_last` пауза не показывается, сразу открывается итог дня.
14. В итоге дня primary — «Готово». «Ещё 7 новых слов» — `secondary` и рендерится только при `extra_new !== null`. Под кнопкой — строка `learn.day.extraNewCost`, она же `accessibilityHint` кнопки.
15. В итоге дня показано не больше 5 строк `advanced`, при `advanced_total > 5` — строка `learn.day.more`.
16. Когда открылась пауза или итог, фокус стоит на заголовке экрана (`accessibilityRole="header"`, на web фокусируемый с `tabIndex -1`).
17. Выбор минут — `SegmentedChoice` с `radiogroup` / `radio` / `checked`. Стрелки меняют выбор.
18. Все иероглифы в блоке, паузе и итоге набраны `HanziText` (`lang="zh-CN"`). У строк с иероглифами `accessibilityLabel` содержит чтение пиньинем.
19. Все фоны, рамки и цвета текста в новых компонентах заданы `className` с парой `dark:`. `useTheme().colors` используется только для пропов `ProgressRing` и `Icon`.
20. Все строки — ключи из §8 в `ru.ts`. Числа с существительными — через `_one/_few/_many`. Литеральной кириллицы в `.tsx` нет.
21. Ни одного сырого hex или px в новых файлах. Тап-таргеты — через `sizing.tapTarget` (или класс `min-h-tap`).
22. Состояния loading / empty / error сессии, паузы и итога реализованы по §5, у каждого есть фикстура.
23. `pnpm typecheck` и `pnpm lint` чистые.
