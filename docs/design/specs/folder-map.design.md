## 1. Контракт

**`FolderMap`** — экран папки:

| Поле | Тип |
| --- | --- |
| `folder` | `{ id, name, word_count, due_count, stage_counts: Record<Stage, number> }` |
| `words` | `{ key, headword, reading, translation, stage: Stage, due: boolean, pair: { partner_headword } \| null, position }[]`, по `position` (порядок добавления) |

**`FolderSummary[]`** — для «Моего словаря»: к существующей папке добавляются `stage_counts` и `due_count`.

**`WordProgress`** — карточка слова, по ключу слова:

| Поле | Тип |
| --- | --- |
| `stage` | `Stage` |
| `skills` | `{ read, pinyin, write, use }`, каждое `"not_started" \| "fresh" \| "holding" \| "stable"` |
| `next_review_days` | `number \| null` (`0` — сегодня, `null` — ещё не учили) |
| `confusions` | `{ partner, partner_reading, status: "active" \| "watch" \| "resolved", resolved_on: string \| null }[]` |

`Stage` = `new \| meeting \| recognize \| recall \| use \| stable`. Всё выше приходит с сервера. Клиент только вычисляет ширину сегментов полоски (`count / word_count`) — это арифметика отображения, как доля `ProgressRing` на Главной.

## 2. Frame (TZ §11)

| Состояние | Primary Action | Secondary Action | Context | Exit |
| --- | --- | --- | --- | --- |
| Папка со словами | `StudyButton` (`folder-study` §3) | тап по плитке → карточка слова; «⋯» → действия с папкой | название, число слов, «пора освежить», полоска стадий, мозаика | «← Назад» |
| Пустая папка | «К поиску» (`EmptyState` action) | «⋯» | пустое состояние | «← Назад» |
| Карточка слова (лист) | нет primary: это справка | «Изменить папки», «Убрать из «Еда»» | стадия, навыки, повторение, путаницы, статья | закрыть лист |
| Действия с папкой (лист) | нет | «Переименовать», «Удалить папку» | название папки | закрыть лист |

**Где теперь «Переименовать» и «Удалить папку».** Раньше это были две кнопки под заголовком (`folder/[id].tsx:94-111`). Теперь главное действие экрана — учить. Редкие действия управления переезжают в лист «⋯» (канон для вторичных действий). Сами потоки (`FolderNameSheet` и лист подтверждения удаления) не меняются.

## 3. Layout

### 3.1 Экран папки

**Узкий экран**, одна колонка, `px-lg`:

```
[← Назад]                                        [⋯]     верхняя строка, высота sizing.tapTarget
Еда                                                      display
18 слов   ( ◌ 4 пора освежить )                          caption textMuted · Chip attention (если due_count > 0)
▓▓▓▓▓▓▓▓▒▒▒▒▒▒░░░░░░░░░░░░░░                             StageBar, sizing.stageBar, radius.pill
● Устойчиво 3  ● Использую 3  ● Вспоминаю 4              StageLegend: только стадии с count > 0,
● Узнаю 2  ○ Новые 6                                     перенос строк, caption
[ ✦ Новые слова · 6 из 6                        → ]      StudyButton — folder-study §3
 или: ( ✎ Практика )
СЛОВА                                                    eyebrow textMuted
┌────┐┌────┐┌────┐                                        WordGrid: мозаика плиток
│火锅 ││豆腐 ││ 葱 │
└────┘└────┘└────┘
┌────┐┌╌╌╌╌┐┌────┐
│筷子 │╎米饭╎│买 ·卖│                                      пунктир = пора освежить; метка пары
└────┘└╌╌╌╌┘└────┘
```

Отступы: верхняя строка → название `spacing.md`; название → строка счёта `spacing.xs`; → полоска `spacing.md`; → легенда `spacing.sm`; → блок учёбы `spacing.lg`; → «СЛОВА» `spacing.xl`; → мозаика `spacing.sm`.

- «← Назад» — `Button ghost` с `Icon arrowLeft`. Текст стоит на линии `px-lg` колонки, а не с отступом кнопки (`dictionary.review.md` m8).
- «⋯» — `IconButton more`, `accessibilityLabel` «Действия с папкой».

**Широкий экран** — как словарь (`today-session` §3.2): левая колонка `sizing.heroColumn` (название, счёт, полоска, легенда, блок учёбы) прилипает к верху. Правая — «СЛОВА» и мозаика. Между ними `spacing.xl`. Раскладка переключается по `onLayout`.

### 3.2 Полоска стадий — `StageBar`

- Сегменты слева направо: `stable` → `use` → `recall` → `recognize` → `meeting` → `new`. Самое прочное слева: папка «заполняется» слева направо.
- Ширина сегмента = `count / word_count`. Сегменты с нулём не рендерятся. Между сегментами зазор `spacing.xs` цвета `background`. Сегмент `new` — `stageNew` с рамкой `stageEdge`.
- При изменении данных сегменты плавно перетекают за `motion.slow`, при reduced motion — сразу.
- **`StageLegend`**: у каждой стадии с `count > 0` `StageDot` + «Название N», `caption`. Цвет не единственный носитель: название и число написаны.

### 3.3 Плитка слова — `WordTile`

- Размер: ширина по сетке (§3.4), высота `sizing.wordTile`. `radius.tile`.
- Заливка — токен стадии: `new` → `stageNew` … `stable` → `stageStable`. Цвет иероглифа: шаги 1–4 — `onStageLight`, 5–6 — `onStageDeep`. У шагов 1–3 рамка `stageEdge`.
- Иероглиф — `HanziText tile` по центру. При 4+ знаках — `HanziText inline`, до двух строк.
- **«Пора освежить»** (`due`): вокруг плитки пунктирная обводка `attention`, толщина `sizing.dueBorder`, отступ от края `spacing.xs`. Пунктир — это узор, а не только цвет, поэтому он виден и без цветового зрения. Красного нет (daily-and-folder-study §5).
- **Пара путаницы** (`pair`): в правом верхнем углу метка `Chip pair` в размере `micro` — `pairSoft`, текст `pairInk`, «·卖» (`HanziText inline`, уменьшенный до `caption`). Выступает за край плитки на `spacing.xs`.
- **«Устойчиво»**: в левом верхнем углу `Icon star` цвета `stageStableMark`, декоративная.
- **Взаимодействие:** наведение (web) — подъём `elevation.raised` сильнее и рамка `focusRing`. Нажатие — `motion.pressScale`. Фокус — кольцо `focusRing`.
- **Переход стадии:** если с прошлого показа стадия плитки выросла (сравнение со своим же кэшем запроса — это не расчёт стадии, а сравнение двух ответов сервера), заливка «наливается» снизу вверх за `motion.slow` и один раз вспыхивает `gradients.heroSheen`. При reduced motion — сразу новый цвет.

### 3.4 Сетка — `WordGrid`

- Колонок: `max(3, floor((ширина + spacing.sm) / (sizing.wordTile + spacing.sm)))`. Ширина берётся из `onLayout` контейнера. Плитки тянутся на всю ширину колонки, зазор `spacing.sm`.
- `FlatList` с `numColumns` (ключ списка зависит от числа колонок) — папка на 300+ слов не должна рендериться целиком.
- Порядок — `position` (как в файле, daily-and-folder-study §5). Переключателя «по стадии» нет (LATER, §8 документа).

### 3.5 Карточка слова — лист `WordSheet`

Тап по плитке открывает существующий `ArticleSheet`. В начало листа добавляется **блок прогресса** `WordProgressBlock`. Он же показывается при открытии сохранённого слова из поиска словаря: одно слово — одна память (daily-and-folder-study §6).

```
买   mǎi                                   ( ● Устойчиво )      HanziText option · pinyinHero · Chip со StageDot
покупать                                                        title
┌ Читаю ──┐┌ Пиньинь ┐┌ Пишу ───┐┌ Использую ┐                 SkillMeter ×4, 2 × 2 на узком, 4 в ряд на широком
│ ▮▮▮      ││ ▮▮▮     ││ ▮▮▯     ││ ▮▮▯       │                 3 деления, заливка stage* по уровню
│ устойчиво││устойчиво││ держится││ держится  │                 caption
└──────────┘└─────────┘└─────────┘└───────────┘
↻ Следующее повторение: через 24 дня                             body, Icon review textMuted
╭ ⇄ Путали с 卖 — различаете с 30 сентября ╮                     ConfusionRow: pairSoft, pairInk
─────────────────────────────────────────                       разделитель border
— статья БКРС (как сейчас) —
[ Изменить папки ]                                              существующая кнопка статьи
[ Убрать из «Еда» ]                                             Button ghost, только при открытии с экрана папки
```

- **`SkillMeter`**: подпись навыка (`caption` семибольд) + 3 деления высотой `sizing.skillPip` + слово состояния. Уровни: `not_started` — 0 делений, «не начат»; `fresh` — 1, «свежий»; `holding` — 2, «держится»; `stable` — 3, «устойчиво». Заливка делений: `fresh` — `stageRecognize`, `holding` — `stageRecall`, `stable` — `stageStable`. Пустые — `surfaceAlt`.
- **Следующее повторение**: `next_review_days` → «сегодня» / «завтра» / «через N дней». При `null` строки нет.
- **Путаницы** — по строке на каждую:
  | `status` | Текст |
  | --- | --- |
  | `active` | «Путаете с 卖 mài — потренируем» |
  | `watch` | «Путали с 卖 mài — проверяем» |
  | `resolved` | «Путали с 卖 — различаете с 30 сентября» |
  Дата — `resolved_on` через `Intl.DateTimeFormat("ru", { day: "numeric", month: "long" })`.
- **«Убрать из «{{folder}}»»** — прямое действие удаления слова из текущей папки, тот же `useRemoveFromFolder`, что у галочки в выборе папок. Подтверждения нет, как у снятой галочки сегодня. После удаления лист закрывается, плитка исчезает (затухание `motion.base`), фокус переходит на соседнюю плитку (следующую, а если её нет — предыдущую), а если слов не осталось — на заголовок папки.
- Старый путь «Изменить папки» → снять галочку остаётся.

### 3.6 Лист «Действия с папкой»

`Sheet`, заголовок — название папки (`heading`). Две строки-кнопки во всю ширину, высота ≥ `sizing.tapTarget`, иконка слева: «Переименовать» (`Icon edit`) открывает `FolderNameSheet` (как сейчас), «Удалить папку» (`Icon trash`) открывает существующий лист подтверждения. Текст обеих — `text`, красного нет. Опасность передаёт подтверждение, а не цвет. После закрытия вложенного листа фокус возвращается на «⋯» (`dictionary.review.md` m1 — фокус не должен падать на `BODY`).

### 3.7 Карточка папки в «Моём словаре» — `FolderCard`

Заменяет `FolderRow` (`MyDictionary.tsx:103-125`).

```
┌────────────────────────────────────────┐
│ Еда                          18 слов   │   heading · caption textMuted
│ ▓▓▓▓▒▒▒▒░░░░░░░░                        │   StageBar size="mini" (sizing.stageBarMini)
│ ( ◌ 4 пора освежить )                   │   Chip attention micro, только при due_count > 0
└────────────────────────────────────────┘
```

- `surface`, `radius.tile`, `elevation.raised`, внутренний отступ `spacing.md`, нажатие — `motion.pressScale`.
- Узкий экран — список, зазор `spacing.sm`. Широкий (правая колонка словаря) — сетка из 2 колонок при ширине ≥ 2 × `sizing.folderCardMin`, иначе список.
- Папка без слов — полоски нет, «0 слов».

## 5. Theming

- Шкала `stage*` в тёмной теме идёт от тёмного к светлому (`today-session` V.7): «Устойчиво» — самый светлый лиловый, папка «наливается светом». Цвет иероглифа меняется парой `onStageLight` / `onStageDeep` из тех же токенов.
- `attention` в тёмной теме — тёмная ветка токена. Пунктир хорошо виден на `background` (≥ 3:1 в обеих темах, V.7).
- Звезда «Устойчиво» в тёмной теме — `stageStableMark` тёмной ветки (тёмная звезда на светлой плитке).
- Все фоны и рамки — `className` с `dark:`. Цвет заливки плитки выбирается картой `stage → className` (`bg-stage-recall dark:bg-stage-recall-dark`), а не через `useTheme()`.

## 6. States

- **Loading (экран):** вместо `LoadingState` — скелет: полоска `surfaceAlt`, 9 плиток `surfaceAlt` с шиммером `motion.slow` (при reduced motion без шиммера). Для диктора — живая область «Открываем папку» (`dictionary.folder.loading`).
- **Error (экран):** существующий `ErrorState` `dictionary.folder.error` + «Попробовать ещё раз».
- **Not found:** существующий `EmptyState` `dictionary.folder.notFound`.
- **Empty (папка без слов):** существующий `EmptyState` `dictionary.folder.empty` + «К поиску». Полоски, легенды, блока учёбы и «СЛОВА» нет. «⋯» есть.
- **Все слова «Новое»:** полоска из одного сегмента `new`, легенда «○ Новые N». Отдельного состояния нет.
- **Прогресс слова в листе:**
  - loading — блок прогресса как скелет (3 серые строки), статья под ним показывается сразу;
  - error — `body textMuted` «Не получилось загрузить прогресс слова.» + `Button ghost` «Попробовать ещё раз». Статья и «Изменить папки» работают;
  - слово ещё не учили (`stage === "new"`) — вместо навыков одна строка «Слово ещё не начато. Оно придёт в «Сегодня» или в раунде папки.».
- **Ошибка «Убрать из папки»:** `FeedbackBanner` `dictionary.picker.error` в листе, лист не закрывается.
- **Карточка папки без сводки** (сводка не пришла, а список папок есть): карточка без полоски и чипа. Сводку не придумываем.

## 7. Accessibility, клавиатура, фокус

| Элемент | Роль и подпись |
| --- | --- |
| `StageBar` | `image`, `accessibilityLabel` «Стадии слов: Устойчиво 3, Использую 3, Вспоминаю 4, Узнаю 2, Новые 6» (нули пропускаются). Легенда рядом — `aria-hidden`, чтобы не читать дважды |
| `WordTile` | `button`, `accessibilityLabel` «火锅, huǒguō, горячий котёл. Узнаю. Пора освежить. Путаете с 卖». Части «Пора освежить» и «Путаете с …» — только когда применимы. `accessibilityHint` «Открывает карточку слова» |
| Сетка | `list` / `listitem` на web |
| «⋯» | `button`, «Действия с папкой» |
| Chip «пора освежить» | текст, не кнопка |
| `SkillMeter` | `accessibilityLabel` «Пишу: держится». Деления — `aria-hidden` |
| Строка путаницы | обычный текст с пиньинем партнёра |
| «Убрать из «Еда»» | `button`, `accessibilityHint` «Слово останется в других папках» |
| `FolderCard` | `button`, «Еда. 18 слов. Пора освежить: 4. Стадии: …». `accessibilityHint` — существующий `dictionary.mine.folderA11yHint` |

- **Клавиатура в сетке (web):** Tab заходит в сетку на первую плитку (roving tabindex), стрелки двигают фокус по сетке с учётом числа колонок, Home / End — к первой и последней плитке, Enter / Space открывают карточку, Tab уходит из сетки.
- После закрытия `WordSheet` фокус возвращается на плитку (`returnFocusRef`, как сейчас со строкой). Если плитку удалили — §3.5.
- Тап-таргеты: плитка ≥ `sizing.wordTile` по высоте, чипы и строки действий ≥ `sizing.tapTarget`.

## 8. Для `design-system-agent`

### Новые токены (в дополнение к `today-session` V.7)

| Токен | Светлая | Тёмная | Зачем |
| --- | --- | --- | --- |
| `sizing.wordTile` | 106 | 106 | минимальная ширина и высота плитки. Вмещает 3 знака `hanziTile` + `spacing.sm` по бокам. На экране 390 даёт 3 колонки |
| `sizing.dueBorder` | 2 | 2 | толщина пунктира «пора освежить» |
| `sizing.stageBar` | 12 | 12 | полоска стадий в шапке папки |
| `sizing.stageBarMini` | 6 | 6 | полоска на карточке папки |

## 10. Acceptance

1. Экран папки получает `FolderMap` одним хуком из репозитория. Стадию, `due`, пары и счётчики клиент не вычисляет. Арифметика — только ширины сегментов `StageBar`.
2. Шапка: «← Назад» с `Icon arrowLeft` и `IconButton more` в одной строке, `display` название, строка счёта с `Chip attention` при `due_count > 0`.
3. «Переименовать» и «Удалить папку» доступны только из листа «⋯». Они открывают существующие `FolderNameSheet` и лист подтверждения, строки и поведение не изменились. После закрытия фокус на «⋯».
4. `StageBar`: сегменты в порядке `stable → … → new`, нулевые не рендерятся, ширина = `count / word_count`. `accessibilityLabel` по §7, легенда `aria-hidden`.
5. `WordTile`: заливка `stage*` по `stage`, текст `onStageLight` для шагов 1–4 и `onStageDeep` для 5–6, рамка `stageEdge` у шагов 1–3. Пунктир `attention` толщиной `sizing.dueBorder` при `due`. `Chip pair micro` при `pair`. `Icon star` при `stable`.
6. `WordTile` набирает иероглиф `HanziText tile`, при 4+ знаках — `inline` до двух строк.
7. `WordGrid`: `FlatList` с `numColumns`, число колонок — по `onLayout` и формуле §3.4, минимум 3. Порядок — `position`.
8. Карточка слова: `WordProgressBlock` в начале `ArticleSheet` для любого сохранённого слова. 4 `SkillMeter` (2 × 2 на узком, 4 в ряд на широком), строка следующего повторения, строки путаниц по `status` с датой через `Intl.DateTimeFormat("ru")`.
9. «Убрать из «{{folder}}»» есть в листе, только если он открыт с экрана папки. Вызывает `useRemoveFromFolder`, затем фокус по §3.5. Путь «Изменить папки» работает как раньше.
10. `FolderCard` в `MyDictionary` заменяет `FolderRow`: название, число слов, `StageBar mini`, `Chip attention micro` при `due_count > 0`. Без сводки — без полоски и чипа.
11. Состояния §6 реализованы. Фикстуры mock есть для: пустой папки, папки только из «Новых», папки на 300+ слов, слова из 4+ знаков, слова с активной, наблюдаемой и решённой путаницей, ошибки прогресса слова.
12. Клавиатура сетки: roving tabindex, стрелки с учётом колонок, Home / End, Enter / Space. После закрытия листа фокус возвращается на плитку.
13. Все анимации (перетекание полоски, «наливание» плитки, шиммер, исчезновение плитки) выключаются при `useReducedMotion() === true`.
14. Цвета плиток задаются картой `stage → className` с `dark:`. `useTheme()` для цвета плитки не используется. Сырых hex и px нет.
15. Уровень HSK на экране папки и в карточке слова не показывается (TZ §4).
16. Строки — ключи §9, литеральной кириллицы в `.tsx` нет.
17. `pnpm typecheck` и `pnpm lint` чистые.
