## 1. Контракт

**`Exercise`** — одно задание:

| Поле | Тип | Для чего |
| --- | --- | --- |
| `task_id` | `string` | |
| `code` | `"intro" \| "R1" \| "R2" \| "P1" \| "P2" \| "W1" \| "W2" \| "C1" \| "C2" \| "pair_card"` | выбор рендерера |
| `lexeme` | `{ headword, reading, tone_label, translation }` | `tone_label` — «3-й тон», от сервера |
| `options` | `{ id, text, kind: "ru" \| "pinyin" \| "hanzi", a11y }[]` | R1, P1, W1, W2, C1. `a11y` — готовое чтение для диктора («mǎi, третий тон») |
| `sentence` | `{ tokens: string[], blank_index: number \| null, ru: string, pinyin?: string }` | C1 (с пропуском), пример в знакомстве |
| `tiles` | `{ id, text }[]` | C2, перемешаны сервером |
| `intro` | `{ example: {zh, pinyin, ru}, char_notes: { char, known_in: string[] }[], actions: "ok" \| "know_or_remember" }` | карточка знакомства |
| `pair` | `{ a: {headword, reading, tone_label, meaning}, b: {…}, difference: string, mnemonic: string \| null, collocations: [string, string] }` | «Разберём пару» |
| `is_retry` | `boolean` | задание вернулось после ошибки (переобучение) |
| `progress` | `{ done, total } \| { learned, total }` | счётчик в шапке. Второй вид — для раунда папки |

**Ответ** `submitAnswer(task_id, answer, latency_ms)`, где `answer` — `{option_id}` \| `{text}` \| `{tile_ids}` \| `{self: "recalled" \| "forgot"}` \| `{blank: true}`. Знакомство и карточка пары — `acknowledge(task_id, choice: "ok" \| "know" \| "remember")`.

**Результат ответа:**

| Поле | Тип | Для чего |
| --- | --- | --- |
| `outcome` | `"correct" \| "partial" \| "wrong"` | цвет лотка. `partial` — тон неверный при верном слоге, верно со второй попытки |
| `correct` | `{ option_id? , text?, tokens? }` | подсветить верное |
| `error_type` | `"blank" \| "confusion" \| "tone" \| "syllable" \| "form_similar" \| "homophone" \| "order" \| "wrong" \| null` | только для выбора иконки и заголовка |
| `partner` | `{ headword, reading, meaning } \| null` | «Это 卖 mài — «продавать»» |
| `explanation` | `string[]` | строки разбора, готовым русским текстом с сервера |
| `next` | `Exercise[]` | вставленные задания (интервенция, «Уже знаю») |
| `progress` | как в `Exercise` | |

`latency_ms` — сырое измерение от показа задания до ответа. Классифицирует скорость сервер.

| R2 — после показа | оценка себя: «Не вспомнил» / «Вспомнил» — **два равных** `SelfRateButton` | — | ответ | крестик |
| P2 | «Проверить» (`Button primary`) | «Не помню» (`Button ghost`) | иероглиф, поле | крестик |

## 3. Оболочка

### 3.1 Раскладка

Полный экран, фон `background`. Контент — колонка `sizing.exerciseColumn` по центру. На узком экране колонка равна ширине экрана минус `spacing.lg` с каждой стороны.

```
┌──────────────────────────────────────────┐
│ [×]  ▓▓▓▓▓▓▓▓▓░░░░░░░░░░         7 / 10  │  шапка: IconButton close · StudyProgress · счётчик
│                                          │
│ ЧТО ЗНАЧИТ?                     [Ещё раз]│  eyebrow textMuted · Chip attention при is_retry
│                                          │
│                  买                       │  «сцена»: HanziText hero, по центру
│                                          │
│ ┌──────────────────────────────────────┐ │
│ │ 1  продавать                         │ │  варианты — нижняя половина экрана:
│ │ 2  покупать                          │ │  на телефоне их достаёт большой палец
│ │ 3  дешёвый                           │ │
│ │ 4  пакет                             │ │
│ └──────────────────────────────────────┘ │
│                                          │
│ ╭──────────── лоток ответа ────────────╮ │  выезжает снизу после ответа (§3.4)
└──────────────────────────────────────────┘
```

- **Шапка:** высота `sizing.tapTarget`, отступы `spacing.md` сверху и снизу. Слева `IconButton close`. По центру `StudyProgress` — толстая полоса `sizing.progressHeight`, `radius.pill`, дорожка `surfaceAlt`, заливка `gradients.primary`. Прирост анимируется за `motion.base`, по заливке один раз пробегает блик. Справа — `caption` tabular «7 / 10» или «3 из 7 слов» (`progress.learned`).
- **Сцена** (подсказка и объект задания) занимает верхнюю часть свободной высоты. Иероглиф стоит по оптическому центру этой области.
- **Варианты** прижаты к низу контента на узком экране и идут сразу под сценой на широком (с отступом `spacing.xl`).
- **Смена задания:** текущее уходит влево с затуханием, новое входит справа, `motion.base` + `motion.easeOut`. При reduced motion — мгновенная смена.

### 3.2 Варианты ответа — `OptionTile`

- Фон `surface`, рамка `border`, `radius.tile`, `elevation.raised`, высота ≥ `sizing.optionMinHeight`.
- На широком экране в углу — `KeyHint` с номером клавиши (`caption`, `textMuted` на `surfaceAlt`, `radius.sm`). На узком его нет.
- **Состояния:**
  | Состояние | Вид |
  | --- | --- |
  | покой | как выше |
  | наведение (web) | рамка `primary` |
  | нажатие | `motion.pressScale` за `motion.fast` |
  | отправлено, ждём сервер | рамка `primary` толщиной `sizing.focusRingWidth`, фон `primarySoft`. Остальные варианты заблокированы, прозрачность `opacity.dimmed`. Если ответ идёт дольше `motion.slow` — под вариантами `caption textMuted` «Проверяем…» |
  | верный | фон `successSoft`, рамка `success`, справа `Icon check` в кружке `success`. Пружина `motion.spring` |
  | выбранный неверный | фон `attentionSoft`, рамка `attention`, подпись `caption attentionInk` «ваш ответ» |
  | остальные после ответа | прозрачность `opacity.dimmed` |
- Цвет никогда не единственный носитель: у верного есть галочка, у выбранного неверного — подпись.

**Сетки по формату:**

| Формат | Варианты | Сетка (обе ширины) | Набор |
| --- | --- | --- | --- |
| R1 | 4 значения по-русски | 1 колонка, во всю ширину | `body` семибольд |
| P1 | 4 пиньиня | 2 × 2 | `title`, `fontFamily.ui` |
| W1, W2 | 6 иероглифов | 3 × 2, плитки квадратные `sizing.hanziChoice` | `HanziText option` |
| C1 | 4 слова | 2 × 2 | `HanziText option` (3+ знака — `sentence`) |

### 3.3 Лоток ответа — `AnswerTray`

Выезжает снизу поверх нижней части экрана за `motion.base`. Скругление верхних углов `radius.hero`, внутренний отступ `spacing.lg`, `elevation.glow`. Варианты над ним остаются видны: лоток не закрывает сцену. На широком экране ширина лотка равна `sizing.exerciseColumn`.

| Исход | Фон | Заголовок | Тело |
| --- | --- | --- | --- |
| `correct` | `successSoft` | `Icon check` (пружина) + «Верно» `heading successInk` | строка `lexeme`: `HanziText inline` + пиньинь + перевод (`body text`) |
| `partial` | `attentionSoft` | «Почти» `heading attentionInk` | строки `explanation` (например, «Слог верный, тон — третий: mǎi») |
| `wrong` | `attentionSoft` | при `partner`: «Это {{партнёр}}» (`HanziText inline` + пиньинь + «значение»), иначе «Правильно — {{ответ}}» | строки `explanation` (`body text`), иероглифы в них — `HanziText inline` |

Под телом — `Button primary` «Дальше» во всю ширину лотка.

**Мягкий разбор** (`vocabulary-engine.md` §11): красного, тряски и звуков ошибки нет. Тёплый янтарный фон и прямой ответ. Разбор — это объяснение, а не наказание.

### 3.4 Выход без потерь

- Крестик, Escape (вне поля ввода и вне IME-набора) и «назад» браузера закрывают сессию сразу, без диалога подтверждения. Каждый ответ уже сохранён (daily-and-folder-study §2.2).
- Если `submitAnswer` ещё в пути, запрос не отменяется при размонтировании. Мутация живёт в `queryClient`, а не в компоненте.
- Возврат — в словарь (для «Сегодня») или на экран папки. Туда же переносится фокус на кнопку, которая открывала сессию.

## 4. Форматы

### 4.1 Знакомство (`intro`)

```
НОВОЕ СЛОВО                                    eyebrow primary
                    买                         HanziText hero, вход: подъём + затухание, motion.spring
              mǎi   [ ˇ 3-й тон ]              pinyinHero textMuted · Chip neutral с tone_label
                 покупать                      title
┌────────────────────────────────────────┐
│ 我想买咖啡。                             │     Card surfaceAlt: HanziText sentence
│ wǒ xiǎng mǎi kāfēi                      │     caption textMuted
│ Я хочу купить кофе.                     │     body
└────────────────────────────────────────┘
[买] уже есть в ваших словах: 买东西 · 买单       body; HanziText inline; или Chip «новый знак» + «Знак 腐 — новый»
[          Запомню          ]                  Button primary        ← папка
[          Уже знаю         ]                  Button secondary      ← папка
[          Понятно          ]                  Button primary        ← «Сегодня» (intro.actions = "ok")
```

- Строк заметки о знаке столько, сколько `char_notes`. Если `known_in` пусто — строка «Знак 腐 — новый» с `Chip neutral` «новый знак».
- Кнопки внизу колонки, на узком экране — у нижнего края.

### 4.2 R1 — значение из 4

Сцена: eyebrow «ЧТО ЗНАЧИТ?», `HanziText hero`. Пиньиня нет: он подсказал бы ответ. Варианты — §3.2.

### 4.3 R2 — вспомнить → показать → оценить

1. Сцена: eyebrow «ВСПОМНИТЕ ЗНАЧЕНИЕ И ЧТЕНИЕ», `HanziText hero`. Внизу `Button primary` «Показать ответ».
2. После нажатия под иероглифом раскрывается `RevealCard` (`surface`, `radius.tile`): `title` перевод, `pinyinHero` чтение. Раскрытие — поворот по X с `motion.spring`, при reduced motion — затухание.
3. Вместо «Показать ответ» — ряд из двух равных `SelfRateButton` одной ширины: «Не вспомнил» (иконка `review`) и «Вспомнил» (иконка `check`). Покой у обоих одинаковый: `surface`, рамка `border`. При нажатии «Вспомнил» заливается `successSoft`, «Не вспомнил» — `attentionSoft`. Лоток после самооценки не выезжает: сразу следующее задание (разбирать нечего).

### 4.4 P1 — пиньинь из 4

Сцена: eyebrow «КАК ЧИТАЕТСЯ?», `HanziText hero`. Варианты 2 × 2, пиньинь `title` шрифтом `fontFamily.ui`. Варианты часто различаются одним тоном, поэтому шрифт обязан иметь все тоновые буквы (V.2).

### 4.5 P2 — набрать пиньинь

```
НАБЕРИТЕ ПИНЬИНЬ
                    买
┌──────────────────────────────┐
│           mai3               │                PinyinInput: title, по центру, radius.tile
└──────────────────────────────┘
            → mǎi                               caption textMuted — предпросмотр
Тон — цифрой после слога: mai3                  caption textMuted
[          Проверить          ]                 Button primary, выключена при пустом поле
              Не помню                          Button ghost → {blank: true}
```

- **Предпросмотр** `mai3 → mǎi` — отображение ввода, не проверка. Преобразование цифр в тоновые знаки — чистая функция рядом с `pinyinPlain` в `shared/lib/dictionaryText.ts`, с тестом.
- Поле: `autoCapitalize="none"`, `autoCorrect={false}`, `spellCheck={false}`, `inputMode="text"`, `enterKeyHint="done"`, `lang="zh-Latn-pinyin"`. Фокус ставится в поле при появлении задания.
- **IME (#41).** Enter во время набора в китайской раскладке (`isComposing`, `keyCode 229` на web) **не отправляет** ответ. Он только подтверждает набор. Проверка — в `shared/platform/` (единственное место, где можно ветвиться по платформе, DoD §17), обёрткой над `onSubmitEditing`. Эту обёртку получает `Input` (§9).
- Если в поле появились иероглифы (включена китайская раскладка), под полем `caption attentionInk`: «Похоже, включена китайская раскладка. Переключите на латиницу.». «Проверить» при этом доступна: сервер разберёт.
- После ответа поле блокируется. При ошибке под ним показан верный ответ, `pinyinHero` + `successInk`.

### 4.6 W1 / W2 — знак из 6

Сцена: eyebrow «КАКОЙ ИЕРОГЛИФ?», перевод `display`. В W1 под ним `pinyinHero` чтение, в W2 чтения нет. Варианты — 6 квадратных плиток 3 × 2 (`sizing.hanziChoice`), `HanziText option`.

### 4.7 C1 — пропуск с выбором

```
ВСТАВЬТЕ СЛОВО
┌────────────────────────────────────────┐
│ 我想 ［    ］ 咖啡。                      │   SentenceCard: HanziText sentence, BlankSlot
│ Я хочу купить кофе.                     │   body textMuted
└────────────────────────────────────────┘
 [ 买 ]  [ 卖 ]
 [ 喝 ]  [ 去 ]                             OptionTile 2 × 2
```

- `BlankSlot` — место шириной в два знака `hanziSentence`, пунктирная нижняя граница `primary`, фон `primarySoft`.
- После выбора слово «перелетает» в пропуск за `motion.base` (при reduced motion — просто появляется). Верно — пропуск становится `successSoft` с текстом `successInk`. Неверно — `attentionSoft`, после «Дальше» пропуск заполняется верным словом.

### 4.8 C2 — сборка фразы из плиток

```
СОБЕРИТЕ ФРАЗУ
Это слишком дорого, я не куплю.                  title
┌────────────────────────────────────────┐
│ [这个] [太] [贵]  ▏                       │     AnswerLine: surface, рамка primary снизу, min-height 2 ряда плиток
└────────────────────────────────────────┘
┌────────────────────────────────────────┐
│ [了] [我] [不] [买]                      │     TileBank: surfaceAlt, radius.tile
└────────────────────────────────────────┘
[          Проверить          ]                  Button primary, активна, когда в AnswerLine ≥ 1 плитка
                Не знаю                          Button ghost → {blank: true}
```

- `WordTile`: `surface`, `radius.tile`, `elevation.raised`, `HanziText sentence`, высота ≥ `sizing.tapTarget`. Нажатие в банке переносит плитку в конец ответа, нажатие в ответе возвращает её на прежнее место в банке. Перенос — layout-анимация `motion.base`. В банке на месте ушедшей плитки остаётся «тень» (`surfaceAlt` темнее, пунктирная рамка `border`), чтобы банк не прыгал.
- Web: Backspace, пока фокус в пределах задания, возвращает последнюю плитку.
- После ответа: при `correct` линия заливается `successSoft`. При `order` или `wrong` линия `attentionSoft`, а под ней строкой `HanziText sentence successInk` — верная фраза (`correct.tokens`).

### 4.9 «Разберём пару» (`pair_card`)

Полноэкранная карточка вместо задания, акцент — малиновый `pair`.

```
РАЗБЕРЁМ ПАРУ                                      eyebrow pairInk
┌──────────────────┐   ┌──────────────────┐
│       买          │ ≠ │       卖          │       две PairColumn рядом (и на 390):
│   mǎi  [ˇ 3]     │   │   mài  [ˋ 4]     │       HanziText hero, pinyinHero, Chip тона
│    покупать      │   │   продавать      │       heading
└──────────────────┘   └──────────────────┘
╭──────────────────────────────────────────╮
│ 卖 = 十 + 买                              │       DifferenceBand: pairSoft, HanziText sentence pairInk
│ «продаёшь — отдаёшь сверху»               │       body text (mnemonic, если есть)
╰──────────────────────────────────────────╯
买东西 · 卖东西                                     HanziText sentence
[          Потренируем          ]                  Button primary
```

- Колонки: `surface`, `radius.tile`, рамка `border`. Знак «≠» между ними — `title textMuted`, `aria-hidden`.
- Вход: колонки въезжают навстречу друг другу за `motion.slow`, полоса различия проявляется следом. При reduced motion — затухание.
- Карточка не оценивается (`acknowledge`). Задания на различение идут после неё обычными форматами.

## 6. States

- **Loading:** первое задание — `LoadingState` сессии (`today-session` §5). Между заданиями загрузки нет. Ожидание ответа сервера — состояние варианта «отправлено» (§3.2) и строка «Проверяем…» после `motion.slow`.
- **Error при отправке ответа:** вместо лотка — `FeedbackBanner` «Не получилось отправить ответ. Проверьте интернет.» и `Button secondary` «Отправить ещё раз». Выбранный вариант остаётся выделенным, остальные заблокированы. Крестик работает. Выход не теряет уже сохранённые ответы, но теряет этот: он не дошёл. Так и написано во второй строке баннера: «Остальные ответы сохранены.»
- **Error в данных задания** (не прошло схему): задание пропускается без экрана ошибки, событие уходит в лог (`events`). Если так пропущены все оставшиеся задания — `ErrorState` сессии.
- **Empty:** сессия без заданий — `today-session` §5 или `folder-study` §6.

## 7. Клавиатура и фокус

| Клавиша | Действие | Где не работает |
| --- | --- | --- |
| `1`–`4` / `1`–`6` | выбрать вариант | фокус в текстовом поле (P2: цифры — часть ответа `mai3`) |
| Enter | «Понятно» / «Проверить» / «Дальше» / «Показать ответ» / «Потренируем» | во время IME-набора |
| `1` / `2` или ← / → | «Не вспомнил» / «Вспомнил» в R2 | до показа ответа |
| Backspace | вернуть последнюю плитку в C2 | фокус в текстовом поле |
| Escape | выйти из сессии | во время IME-набора; при открытом `Sheet` |

- Сокращения вешаются одним обработчиком на оболочку (`keydown` на web через `shared/platform/`). Каждый рендерер регистрирует свои действия.
- **Фокус при новом задании** — на заголовок сцены (`accessibilityRole="header"`, `tabIndex -1`). Его `accessibilityLabel`: «Задание 7 из 10. Что значит 买?». Исключение — P2: фокус в поле, а подсказка — в его `accessibilityLabel`.
- **Фокус после ответа** — на «Дальше» в лотке. Лоток — `accessibilityLiveRegion="polite"`, итог объявляется сам.
- Кольцо фокуса — `focusRing`, `sizing.focusRingWidth`, у всех интерактивных элементов.

## 11. Acceptance

1. Сессия и её задания рендерятся вне `(tabs)`: в дереве экрана задания нет `TabList`.
2. Оболочка: `IconButton close`, `StudyProgress` и счётчик в шапке. Колонка контента ограничена `sizing.exerciseColumn`.
3. Для каждого `code` из §1 есть отдельный рендерер. Неизвестный `code` или объект, не прошедший схему, пропускается без экрана ошибки и пишется в лог.
4. Ни один рендерер не сравнивает ответ с правильным. Цвет варианта, заголовок лотка и подсветка верного берутся из результата `submitAnswer` (`outcome`, `correct`, `partner`, `explanation`).
5. Варианты: R1 — одна колонка, P1 и C1 — 2 × 2, W1/W2 — 3 × 2 квадратов `sizing.hanziChoice`. На обеих ширинах.
6. Состояния `OptionTile` (покой, наведение, нажатие, отправлено, верный, выбранный неверный, остальные) реализованы по §3.2. У верного есть `Icon check`, у выбранного неверного — подпись «ваш ответ».
7. Лоток: `correct` — `successSoft` / `successInk`, `partial` и `wrong` — `attentionSoft` / `attentionInk`. Токены `danger` и `warning` в `features/study/exercise/*` не встречаются.
8. В R2 после показа ответа два `SelfRateButton` равной ширины и одинакового вида в покое. `Button variant="primary"` в этом состоянии нет.
9. P2: Enter во время IME-набора не вызывает `submitAnswer`. Защита живёт в `shared/platform/`, `Platform.OS` вне неё не используется.
10. P2: `autoCapitalize="none"`, `autoCorrect={false}`, `spellCheck={false}`. Предпросмотр `mai3 → mǎi` — чистая функция в `shared/lib/dictionaryText.ts` с тестом минимум на `mai3`, `lv4 → lǜ`, `nü3`, `ma5 / ma`.
11. P2: при иероглифах в поле показана строка `learn.ex.p2.ime`.
12. C2: плитка переносится между банком и ответом нажатием. На месте ушедшей плитки в банке остаётся «тень». Backspace возвращает последнюю плитку. «Проверить» неактивна при пустом ответе.
13. «Разберём пару»: две `PairColumn` рядом на обеих ширинах, `DifferenceBand` на `pairSoft`, primary «Потренируем» → `acknowledge`.
14. Клавиши §7 работают на web. Цифры не перехватываются, пока фокус в текстовом поле. Escape не срабатывает во время IME-набора.
15. Фокус при новом задании — на заголовок сцены (для P2 — в поле). После ответа — на «Дальше». Лоток — живая область `polite`.
16. Крестик, Escape и «назад» браузера закрывают сессию без диалога. Отправка ответа в пути при этом не отменяется.
17. Ошибка отправки: `FeedbackBanner` `learn.ex.submitError` и «Отправить ещё раз». Выбор сохраняется на экране.
18. Все иероглифы — `HanziText` (`lang="zh-CN"`, `fontFamily.hanzi`). Сцена: `hero` при 1–2 знаках, `heroLong` при 3+. Пиньинь — `fontFamily.ui`.
19. Все анимации (смена задания, пружина, лоток, раскрытие R2, перелёт в пропуск, перенос плиток, въезд пары) выключаются при `useReducedMotion() === true`.
20. Фон, рамки и цвета текста — `className` с `dark:`. Сырых hex и px нет. Длительности — `motion.*`.
21. Строки — ключи §10, литеральной кириллицы в `.tsx` нет.
22. `pnpm typecheck` и `pnpm lint` чистые.

## 13. Open Questions

1. **К владельцу.** Каждый ответ ждёт сервер, прежде чем показать итог: состояние «отправлено», затем лоток. На хорошей сети это доли секунды, на плохой задания будут «липкими». Можно класть ключ ответа в `Exercise`, показывать итог сразу, а сервер пусть классифицирует и пишет состояние. Это исключение из TZ §3 (правило 1) и `DESIGN_LOOP.md` §3 (gate A п. 2), решать владельцу. На вёрстку не влияет: исчезнет только состояние «отправлено».
2. **К владельцу.** В «Сегодня» у знакомства одна кнопка «Понятно» (как в `vocabulary-engine.md` §11), в папке — «Запомню» / «Уже знаю». Давать «Уже знаю» и в «Сегодня»? Для загрузок из учебника это экономит время. Спека поддерживает оба варианта через `intro.actions`.
3. **К владельцу.** Строки `[предл.]` §10 — подтвердить до gate B.
