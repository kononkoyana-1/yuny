## Визуальный язык (#65, решение владельца 2026-09-24)

1. **Один главный акцент на экране.** Всё остальное нейтральное
   (`surface`, `text`, `textMuted`). Одна кнопка `primary` на экран или лист.
2. **Цвет несёт смысл, один на всё приложение:** фиолетовый `primary` и
   шкала `stage*` — действие и память (глубже — прочнее); мятный `success` —
   верно; янтарный `attention` — «пора освежить», мягкий разбор ошибки;
   малиновый `pair` — пара путаницы; `destructive` — только разрушительное
   действие. Ошибка ученика — не красная.
3. **Иероглиф — главный объект.** Своё семейство и шкала `typography.hanzi*`.
4. **Живые состояния:** нажатие, выбор, ответ — микроанимация `motion.*`;
   при `prefers-reduced-motion` — мгновенно или затухание. Движение никогда
   не единственный носитель смысла.
5. **Без пустой геймификации:** нет XP, лиг, огня серии. Праздник — только
   за реальный результат (слово выросло на стадию, пара решена).
6. Текущий вид приложения и `assets/image/design.png` — **не образец**.

Полная таблица значений токенов #65 — `docs/design/specs/today-session.design.md`

## Правила экрана

- Primary Action, Context, Exit; у каждого блока с данными — загрузка,
  пусто, ошибка с повтором. Экран не блокируется целиком, если может
  показать часть без сети.
- **Клиент ничего не считает про память:** стадии, сроки, правильность
  ответа, квоты приходят с сервера (TZ §3). Клиент только рисует и делит
  `count / total` для ширины полосок.
- Тон текста: тёплый, взрослый, коротко; без кодов ошибок и слов «сервер»,
  «API», «сессия». Числа с существительными — `_one/_few/_many`. Все
  строки — ключи в `apps/mobile/shared/i18n/ru.ts`.

## Доступность и веб-особенности (на них уже спотыкались)

- Тап-таргет ≥ 44 (`sizing.tapTarget`), видимое кольцо фокуса на
  `:focus-visible`, контраст текста ≥ 4.5:1 (крупного ≥ 3:1) в обеих темах.
- react-native-web 0.21 переводит `aria-*`, но **не** `accessibilityState`
  → ставить `aria-checked`, `aria-selected`, `role` явно (образец —
  `features/dictionary/CheckMark.tsx`). Пробел жмёт только `role=button` —
  для радио/чекбоксов обрабатывать `onKeyDown`.
- Ширина — по `onLayout` контейнера, **не** `useWindowDimensions` (#56).
- Тёмная тема — класс `dark` на `<html>` (`darkMode: "class"`), выбор в
  `shared/lib/themePreference.ts`; цвета в JS — только через `useTheme()`,
  не `useColorScheme` из react-native.
- Цвета фона, рамок, текста — `className` с парой `dark:`.
- `ref` — обычный проп (React 19); фокус после закрытия `Sheet` возвращать
  явно.

## Два пути задачи (подробно — `docs/DESIGN_LOOP.md` §2)

- **Полный** — новый сценарий или экран с новой механикой: спека gate A →
  сборка → gate B.
- **Лёгкий** — служебный экран или правка в готовом визуальном языке:
  чек-лист в самой задаче → сборка → один gate B по скриншотам.
