# Ежедневные повторения и изучение по папке

Статус: решения владельца приняты (раздел 9) · 2026-09-23 · ветка `feature/vocab-learning-engine`
Опирается на `vocabulary-engine.md` (навыки, FSRS, пары путаницы, контекст).
Вёрстку и визуальный язык решает `ui-designer` (gate A). Здесь — механика и
смысл экранов, наброски в ASCII — только чтобы договориться о содержании.

---

## 1. Главная идея: один движок, два входа

```
                     ┌──────────────────────────────┐
  «Сегодня»  ──────▶ │   одна память на слово:       │ ◀────── «Учить папку»
  (приходит само)    │   4 навыка · FSRS · путаницы  │         (когда хочу я)
                     └──────────────────────────────┘
```

- **«Сегодня»** отвечает за то, чтобы **не забывать**. Все папки, только то,
  что пора, плюс немного новых слов. Приходит само: раз в день окно «Повторим?» с выбором 5, 10 или 15 минут (по умолчанию 10).
- **«Учить папку»** отвечает за то, **что я хочу выучить сейчас**: к поездке,
  к уроку, к контрольной. Запускает пользователь.

Состояние памяти общее, поэтому режимы не конфликтуют:

- слово, повторённое в папке, **выпадает из «Сегодня»** — сегодня его уже
  вспоминали;
- новые слова, начатые в папке, **расходуют ту же дневную квоту новых**;
- занятие папкой **не ломает расписание**, даже если там нечего повторять
  (раздел 3.3).

**Почему не «урок = папка» всегда.** Десять видов еды подряд — это слова
одного смыслового поля, введённые одновременно, а они путаются друг с другом
заметно чаще (интерференция). Поэтому папочный режим свои порции **строит**:
7 слов за раунд, развести похожие, подмешать знакомое. Так он остаётся
«по папке» для пользователя и не вредит памяти.

---

## 2. «Сегодня» — ежедневные повторения

### 2.1 Из чего собирается

По порядку приоритета (подробно — `vocabulary-engine.md`, раздел 3):

1. **Пары путаницы**, у которых подошёл срок (买/卖).
2. **Повторения**: все (слово, навык), где вероятность вспомнить упала ниже
   90%. Сначала самые просроченные.
3. **Новые слова** — сколько влезает в бюджет с учётом завтрашней нагрузки
   (обычно 3–8). Берутся из очереди: папка в фокусе → недавно созданные
   папки → остальные.
4. **Сцена** одной «готовой» папки — раз в несколько дней, последним блоком
   (раздел 4).

### 2.2 Форма сессии: порции по 8–10 заданий

Сессия нарезана на **порции**. После каждой порции — короткая пауза с
итогом и выбором «ещё порцию / хватит».

- **Прерваться можно в любой момент без потерь.** Каждый ответ сохраняется
  сразу, а самые срочные задания идут первыми. Поэтому 3 минуты из 8 — это
  всё равно главная польза, а не «брошенный урок».
- **Долг не сгорает.** Если накопилось 120 заданий, «Сегодня» берёт бюджет
  (например, 40), а остальное растягивает на несколько дней. Новые слова при
  этом — 0, и экран честно объясняет почему.

### 2.3 Ежедневное окно «Повторим?»

Раз в день, при первом открытии приложения, если «Сегодня» ещё не пройдено и
есть что повторить, поверх словаря всплывает окно:

```
┌──────────────────────────────┐
│  Повторим слова?              │
│  26 пора освежить · 5 новых   │
│                               │
│   ( 5 мин ) ( 10 мин ) ( 15 мин )│
│                               │
│  [   Начать · 10 минут    ]   │
│          Позже                │
└──────────────────────────────┘
```

- 10 минут выбрано по умолчанию; последний выбор запоминается и
  становится выбором по умолчанию на завтра.
- Минуты переводятся в число заданий по средней скорости пользователя
  (на старте ~4 задания в минуту: 5 → ~20, 10 → ~40, 15 → ~60).
- Бюджет влияет и на квоту новых слов: при 5 минутах новых меньше, при 15 —
  больше, в пределах нагрузки на завтра.
- «Позже» закрывает окно до завтра; блок «Сегодня» в словаре остаётся.
- Нечего повторять и нет новых — окно не показывается.

### 2.4 Экраны

**Блок «Сегодня» наверху вкладки «Словарь»** (решение владельца: «Словарь» —
первая вкладка и стартовый экран, отдельной вкладки «Сегодня» нет)

```
┌─────────────────────────────────────┐
│  Сегодня                             │
│                                      │
│  ◐  34 задания · ~8 минут            │
│                                      │
│  Повторить         26                │
│  Новые слова        5  из «Покупки»  │
│  Разобрать пару     买 / 卖           │
│                                      │
│  [        Начать        ]            │
│                                      │
│  Сейчас вы вспомните ~212 из 347     │
│  Завтра: ~30 заданий                 │
└─────────────────────────────────────┘
```

**Пауза между порциями**

```
┌─────────────────────────────────────┐
│  Порция 2 из 4 готова                │
│                                      │
│  ✓ 9 из 10 вспомнили                 │
│  便宜 теперь «Вспоминаю»              │
│                                      │
│  [ Дальше ]        [ Хватит ]        │
└─────────────────────────────────────┘
```

**Итог дня**

```
┌─────────────────────────────────────┐
│  Готово на сегодня                   │
│                                      │
│  Продвинулись        7 слов          │
│    袋子  Узнаю → Вспоминаю            │
│    小票  Вспоминаю → Использую        │
│    …                                 │
│  Пара 买/卖 — различаете              │
│                                      │
│  Завтра ~28 заданий                  │
│  [ Ещё 7 новых слов ]  [ Закрыть ]   │
└─────────────────────────────────────┘
```

«Ещё 7 новых» — по желанию, с предупреждением о нагрузке: «+~12 заданий
завтра».

**Когда повторять нечего:** «На сегодня всё. Следующее повторение — завтра.
Можно поучить папку →». Это честнее, чем гонять слова раньше срока.

## 3. «Учить папку» — изучение по папке

### 3.1 Одна кнопка, режим подбирается сам

На экране папки — одна главная кнопка. Движок сам выбирает, что нужнее
**этой папке сейчас**, и подписывает кнопку:

| Состояние папки | Кнопка | Что будет |
|---|---|---|
| есть слова, которым пора | **Повторить · 12** | повторения только этой папки |
| есть новые слова | **Новые слова · 7 из 18** | раунд знакомства (3.2) |
| всё свежее, ничего не пора | **Практика** | упражнения в контексте (3.3) |
| ≥ 5 слов на «Вспоминаю» и сцена не проходилась неделю | **Сцена готова** | мини-миссия (раздел 4) |

Порядок: повторения → новые → сцена → практика. Остальные режимы доступны
второстепенной строкой под кнопкой («или: новые слова · проверка папки»).

### 3.2 Раунд знакомства — главный механизм папки

**7 новых слов за раунд** (решение владельца; не 15). Это верхняя граница того, что
удерживает рабочая память, если каждое нужно вспомнить несколько раз. Нужно
15 — это 2–3 раунда, и между ними пауза.

**Шаги раунда (~6–8 минут):**

1. **Знакомство** — карточка на каждое слово:
   ```
   ┌──────────────────────────────┐
   │            豆腐               │
   │           dòufu               │
   │           тофу                │
   │                               │
   │   麻婆豆腐 — тофу по-сычуаньски │
   │   Знак 腐 — новый              │
   │                               │
   │  [Уже знаю]        [Запомню]  │
   └──────────────────────────────┘
   ```
   - **«Уже знаю»** не верится на слово: сразу даётся трудная проверка
     (вспомнить значение и пиньинь без вариантов). Прошёл — слово
     стартует со стабильностью ~7 дней и не тратит время раунда. Не
     прошёл — обычное знакомство. Это важно для загрузок из учебника,
     где половина слов уже знакома.
   - У каждого слова **своя коллокация-якорь** (吃火锅, 买豆腐, 切葱). Разные
     ситуации разводят похожие слова одного поля и снижают путаницу.

2. **Вспомнить каждое 2 раза, вразбивку.** Упражнения идут вперемешку по 7
   словам, плюс 2–3 уже знакомых слова из других папок для перемешивания.
   Правило: каждое новое слово нужно **вспомнить верно дважды**, с другими
   заданиями между попытками. Ошибся — слово вернётся через 2–3 задания
   (метод последовательного переобучения: вспоминать до успеха внутри
   сессии, потом разносить по дням).
   - Сначала лёгкие форматы: значение из 4 вариантов, пиньинь из 4.
   - Второй раз — трудные: вспомнить без вариантов, набрать пиньинь.
   - **Дистракторы на первом круге — не из этого же раунда.** Слова,
     увиденные минуту назад, в вариантах только сбивают. На втором круге
     уже можно: там учимся их различать.

3. **Мини-контекст.** По одному пропуску на слово: коллокация-якорь (T1).

4. **Итог раунда:**
   ```
   ┌──────────────────────────────┐
   │  5 новых слов в «Еда»         │
   │  火锅 豆腐 葱 金针菇 辣椒       │
   │  ■■□□□□  6 из 18 начаты        │
   │                               │
   │  Вернутся завтра в «Сегодня»  │
   │                               │
   │  [Ещё 7 слов]   [Хватит]      │
   └──────────────────────────────┘
   ```
   «Ещё 7» после двух раундов подряд показывает нагрузку: «Завтра будет ~45
   заданий». Решает пользователь, но информированно.

**Что не делаем в раунде:** matching (решается исключением), сборку знаков
из компонентов, ПИШУ до того, как слово узнаётся хотя бы 3 дня.

### 3.3 Практика: когда пора нечего, а хочется

Пользователь открыл папку, а всё свежее. Здесь ловушка: **повторять раньше
срока почти бесполезно для памяти**, но запретить нельзя — человек хочет
заниматься.

Решение: давать **другую работу**, не те же карточки.

- Упражнения в контексте (сборка предложения из плиток, пропуск без
  вариантов) на словах папки. Это тренирует ИСПОЛЬЗУЮ, где запас есть почти
  всегда.
- Расписание не ломается само по себе. В формуле FSRS прирост
  пропорционален `e^(1−R) − 1`, а при R ≈ 1 он почти ноль. Досрочный верный
  ответ интервал не раздувает, ошибка честно его сокращает. Ничего
  специального делать не нужно.
- Интерфейс говорит правду: «Эти слова пока держатся. Практика в
  предложениях поможет их использовать».

### 3.4 Проверка папки — перед контрольной или поездкой

По кнопке «Проверить папку»:

- все слова папки, **один раз каждое**, трудный формат, без подсказок;
- результат — список «вспомнил / не вспомнил» и готовность: «Вспомнили 18
  из 25»;
- ответы идут в память как обычные: проваленные слова вернутся в
  «Сегодня» раньше;
- кнопка «Повторить 7 проваленных» — сразу раунд только по ним.

Это заменяет желание «прогнать всю папку карточками», но с пользой:
каждый ответ — честное измерение.

### 3.5 Цель папки

В настройках папки — одна из трёх:

| Цель | Что меняется |
|---|---|
| **Учу** (по умолчанию) | обычная очередь новых слов, все 4 навыка |
| **К дате** — «Поездка 15 октября» (**позже**, решение владельца) | новые слова папки распределяются равномерно до даты; ближе к дате цель удержания поднимается до 0.93, за 2 дня — проверка папки в «Сегодня» |
| **Только читать** | меню, вывески, справочник: навык ПИШУ не открывается |
| (выключено) **Не учить** | папка — просто хранилище, в очередь не попадает |

«К дате» — сильная механика для настоящего поведения: люди учат китайский
к конкретным событиям.

## 4. Сцена папки — связать слова в ситуацию

Открывается, когда в папке **≥ 5 слов на «Вспоминаю»**. Не раньше: сцена из
незнакомых слов — это чтение со словарём, а не практика.

- Одна ситуация на 4–6 реплик, **только** из слов папки на «Вспоминаю» и
  выше плюс известных пользователю слов (проверяет код, см.
  `vocabulary-engine.md`, раздел 7).
- 5–8 заданий по ходу диалога: выбрать реплику → вставить пропуск →
  собрать реплику из плиток → перевести одну реплику.
- В конце — сцена целиком, её можно прочесть. Тап по слову — его карточка.
- Пересобирается, когда в папке прибавилось ≥ 5 готовых слов. Старые сцены
  остаются в папке, их можно перечитать.

```
┌─────────────────────────────────────┐
│  Сцена · На рынке          3 / 7    │
│                                      │
│  老板：你要什么？                      │
│  你：  我要两个 ______ 。              │
│        (перец чили)                   │
│                                      │
│   辣椒     豆腐     葱     袋子         │
└─────────────────────────────────────┘
```

## 5. Экран папки — «карта слов»

Здесь красота и польза совпадают: папка показывается **сеткой плиток-слов**,
и состояние каждого слова видно сразу.

```
┌─────────────────────────────────────┐
│  Еда                         18 слов │
│  ▓▓▓▓▓▓▒▒▒▒░░░░░░░░                 │
│  Устойч. 3 · Использую 3 · Вспоминаю │
│  4 · Узнаю 2 · Новые 6               │
│                                      │
│  [      Новые слова · 6 из 6      ]  │
│   или: повторить · сцена · проверка  │
│                                      │
│  ┌────┐┌────┐┌────┐┌────┐┌────┐      │
│  │火锅 ││豆腐 ││ 葱 ││辣椒 ││金针菇│      │
│  │████││███░││██░░││█░░░││    │      │
│  └────┘└────┘└────┘└────┘└────┘      │
│  ┌────┐┌╌╌╌╌┐ …                       │
│  │筷子 │╎米饭╎  ← пунктир: пора освежить │
│  └────┘└╌╌╌╌┘                         │
└─────────────────────────────────────┘
```

- **Насыщенность плитки = стадия.** Новое — пустая, «Устойчиво» — полная.
  Шкала одна для всего приложения (цвета — токены дизайн-системы).
- **Пунктир** — слово пора освежить (вероятность вспомнить < 90%). Честно и
  без тревожного красного.
- **Метка пары** на плитке, если слово в активной путанице (买·卖).
- Тап по плитке — карточка слова: 4 сегмента навыков, когда следующее
  повторение, с чем путали.
- Сортировка по умолчанию — порядок добавления (как в файле), переключатель
  «по стадии».

Главное — пользователь видит, как папка **заполняется цветом**. Это
прогресс, который нельзя накрутить: плитка темнеет только от вспоминаний
на растущих интервалах.

На вкладке «Словарь» у карточки папки — та же полоска стадий в миниатюре и
счётчик «пора освежить: 4».

## 6. Как режимы делят новые слова и нагрузку

```
дневной бюджет новых = quota(прогноз завтрашней нагрузки)   напр. 6

  «Учить папку» · раунд 7 слов    →  потрачено 6, квота исчерпана
  «Сегодня»                       →  новых не возьмёт
  «Ещё 7» в папке                 →  можно, сверх квоты, с предупреждением
```

- Квота одна. Папка может её превысить — пользователь главный, но видит
  цену («завтра ~45 заданий»).
- Повторения из папки засчитываются в «Сегодня» — задание не будет
  спрошено дважды за день.
- Слово в двух папках — одна память; в каждой папке плитка показывает одно
  и то же.
- Папка «в фокусе» или «К дате» получает новые слова в «Сегодня» первой.

## 7. Напоминания

- Одно в день, во время, которое выбрал пользователь, и только если
  «Сегодня» не пройдено. Текст — о деле: «8 минут: 26 слов пора освежить».
- Для папки «К дате» — за 2 дня: «До поездки 2 дня. Проверим „Еда“?»
- Никаких «Юни грустит без тебя».

## 8. Что входит в MVP

**MUST**

- «Сегодня»: ежедневное окно 5 / 10 / 15 минут, сборка по приоритету, порции по 8–10, пауза с итогом, итог
  дня, растягивание долга, квота новых от нагрузки.
- Папка: кнопка с автоматическим режимом, раунд знакомства (7 слов,
  «Уже знаю» с проверкой, 2 верных вспоминания вразбивку, коллокация-якорь),
  карта слов с плитками.
- Общая квота новых и учёт повторений между режимами.

**SHOULD**

- Проверка папки.
- Цели папки: «Только читать», «Не учить».
- Сцена папки.
- Практика в контексте для папки, когда повторять нечего.

**LATER**

- Цель папки «К дате» и напоминание перед датой.
- Перечитывание старых сцен.
- Сортировки и фильтры карты слов.

## 9. Решения владельца (2026-09-23)

1. **Раунд папки — 7 слов.**
2. **Бюджет по умолчанию — 10 минут.** Каждый день всплывает окно с выбором
   5 / 10 / 15 минут (раздел 2.3).
3. **«Сегодня» — блок в «Словаре»**, «Словарь» открывается первым.
4. **Цель папки «К дате» — позже.** «Только читать» и «Не учить» — тоже не в
   первой очереди (SHOULD).
5. Эта механика **заменяет модули и уроки** старого ТЗ (TZ.md §7–§10).
