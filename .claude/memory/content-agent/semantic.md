# Semantic Memory — content-agent

Generalizations that survived repetition. An episodic entry becomes a rule
here only after the same thing happened more than once — a single occurrence
is an anecdote, not a rule.

## The dominant defect class is the accidentally-valid alternative answer

Both blockers in the first reviewed package were the same thing: a `fill_blank`
where a word other than the target also fits. The validator cannot catch this —
it only detects the answer repeated inside its own sentence. Before handoff,
read every blank asking "what else fits here?" and prefer a frame where grammar
(an article, a preposition, a following clause) excludes the alternatives
rather than one where only context suggests the answer.
