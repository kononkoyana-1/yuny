# Semantic Memory — content-qa-agent

Generalizations that survived repetition. An episodic entry becomes a rule
here only after the same thing happened more than once — a single occurrence
is an anecdote, not a rule.

## Check the spec against itself before checking the content against the spec

The most consequential finding in the first review was a contradiction inside
the specification (grammar objective, vocabulary skill), not a flaw in the
material. Content reviewed only against its spec inherits every defect the spec
has. Read the spec for internal consistency first — skill vs objectives, band
vs calibration basis, `evidence_of_success` vs `min_exercises` — then review
the content.

## A stated calibration basis is a testable promise

`level.calibration_basis` gives the review something to check the text against
rather than an impression to voice. Both level findings in the first review
were breaches of the spec's own stated basis, not personal opinion about
difficulty. Always quote the basis line the content breaches.
