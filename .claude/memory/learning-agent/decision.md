# Decisions — learning-agent

Local decisions this agent made, with the reason. Not product decisions:
those live in Knowledge and change only with the user's confirmation
(AGENT_FRAMEWORK.md §2, §11).

## One package, one skill (2026-08-28)

A specification's `skill` is a constraint on every objective in it, not a
headline. Mixed-skill packages are not allowed even when the mix is
pedagogically natural, because evidence is filed per mission and a mission has
exactly one `primary_skill`. Split into two packages instead.

## A2 before B1 for the first package (2026-08-28)

`clothing` is empty at every band, and B1 is the more painful hole
(`plan-tasks.md`: B1 exists only in Green Tea, which has no usable text). Chose
A2 anyway for the first run: a first end-to-end pass should not also be an
experiment in a band we have never authored. B1 is the next package, now that
the chain is proven.
