# Semantic Memory — ui-designer

Обобщения, выведенные из повторившихся episodic-записей. Пусто, пока паттерн
не повторился в нескольких задачах.

Что сюда попадает по природе роли: формулировки Acceptance-пунктов, которые
систематически оказывались непроверяемыми; места спеки, которые разработчик
регулярно понимал иначе; типы дефектов, повторяющиеся из раунда в раунд.
